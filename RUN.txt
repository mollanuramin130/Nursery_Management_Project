GreenLeaf Nursery — how to run (simple)

Order every time:
1. MySQL
2. API  (must stay running — use --host=0.0.0.0 for phones)
3. Website / Admin / Apps

QA testing: docs/QA_TESTING_POLICY.md (unit/API/client tests required; no COMPLETE without evidence).

--------------------------------
QA-01 connectivity checklist
--------------------------------
# API must be healthy:
curl http://127.0.0.1:8000/api/v1/health/ready
# expect: {"status":"ok","database":"healthy",...}

# Or:
cd apps/nursery-api && bash scripts/qa01_smoke.sh

CORS in API .env must include:
  http://localhost:3000, http://127.0.0.1:3000
  http://localhost:3001, http://127.0.0.1:3001

Physical Android: do NOT use 10.0.2.2 — use Mac LAN IP.


--------------------------------
1) MySQL
--------------------------------
- Start MySQL (XAMPP or your MySQL)
- Database name: nursery_local
- Load sample data once: database/nursery_sample_data.sql


--------------------------------
2) API (must stay running)
--------------------------------
cd apps/nursery-api
composer install
php artisan serve --host=0.0.0.0 --port=8000

Open: http://127.0.0.1:8000/api/v1
Health: http://127.0.0.1:8000/api/v1/health/ready


--------------------------------
3) Customer Website
--------------------------------
# From repo root, npm run dev FAILS (no root package.json). Always:
cd apps/nursery-web
cp .env.example .env.local
# NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8000/api/v1
# If you open http://192.168.x.x:3000 (phone/LAN), also set:
# NEXT_DEV_ALLOWED_ORIGINS=192.168.1.3
npm install
npm run dev

# Prefer this URL (matches Next "Local") — Add to cart works here:
Open: http://localhost:3000
# LAN (http://192.168.x.x:3000) also works in dev: browser uses /backend-api
# proxy to Laravel (see next.config rewrites). Set NEXT_DEV_ALLOWED_ORIGINS to your IP.
Login page shows API readiness banner.


--------------------------------
4) Admin Website
--------------------------------
cd apps/nursery-admin
cp .env.example .env.local
npm install
npm run dev

# Prefer:
Open: http://localhost:3001
# Or http://127.0.0.1:3001 (allowedDevOrigins includes 127.0.0.1)


--------------------------------
5) Customer Android App
--------------------------------
cd apps/nursery_app
flutter pub get

# Emulator:
flutter run

# Physical phone (same Wi-Fi as Mac):
ipconfig getifaddr en0
flutter run -d <DEVICE_ID> --dart-define=API_BASE_URL=http://YOUR_LAN_IP:8000/api/v1

# If phone cannot reach LAN IP (AP isolation / band mismatch), USB tunnel:
adb reverse tcp:8000 tcp:8000
flutter run -d <DEVICE_ID> --dart-define=API_BASE_URL=http://127.0.0.1:8000/api/v1
# Debug/profile APKs allow cleartext; release still requires HTTPS.


--------------------------------
6) Admin Android App
--------------------------------
cd apps/nursery_admin_mobile
flutter pub get

# Emulator:
flutter run

# Physical phone:
flutter run -d <DEVICE_ID> --dart-define=API_BASE_URL=http://YOUR_LAN_IP:8000/api/v1
# Or: adb reverse tcp:8000 tcp:8000 + API_BASE_URL=http://127.0.0.1:8000/api/v1
