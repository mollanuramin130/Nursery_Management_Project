# PHASE 19 — Admin Mobile UI/UX

## Identity

- Brand: **GreenLeaf Ops** (not customer shop UI)
- Palette: deep green `#1A5C3A` / `#0F3D28`, neutral surfaces, high-contrast status chips
- Typography: Figtree (Google Fonts)
- Dense operational cards; no marketing heroes

## Patterns

- Debounced search (400ms) for orders/inventory
- Confirm dialogs for adjust / receive / cancel / logout
- Preview adjustment math is **display only**; API response refreshes truth
- Empty / error / loading states on all primary lists
- One-handed primary actions (bottom nav + filled buttons ≥48px)

## Screens

Login · Dashboard · Orders list/detail · Inventory list/detail/adjust/movements/scan · PO list/detail/receive · Suppliers · Warehouses · Notifications · Profile/More
